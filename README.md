# PingPong Lab

纯数据录入的乒乓球复盘 PWA。无视频、账号业务或云同步，比赛数据存储在当前浏览器 IndexedDB。

## 本地运行

在本目录执行 `node server.mjs`，访问 http://localhost:4173 。运行逻辑测试：`node test.mjs`。

`dist` 为完整静态应用，可部署到 HTTPS 静态主机。安卓平板使用 HTTPS 地址打开，浏览器菜单添加到主屏幕。局域网 HTTP 地址只供在线预览，不能据此验证 PWA 离线能力。

## 功能

比赛与多局管理、标准 11 分制单打自动计分和换发、逐分撤销编辑删除、发球方手动修正、关键一板标签与九宫格落点、击球时期和身体位置/距离/高度、自由备注、自定义标签、对手长期笔记、当场总结、单局/整场/历史统计与对手筛选、统计回查、JSON 完整备份恢复和 CSV 导出。

标签默认选填。每分每类标签目前单选，自定义标签可逗号分隔。落点以接球者正反手为准。回合从发球第 1 板计算。统计标签只覆盖填写过的数据；原因分布只统计失分。修改历史记录后比分和自动发球方重新计算，手动发球方保留。

## 实机验收

1. 新建比赛，记录 100 分以上，修改/删除记录检查比分与统计。
2. 关闭浏览器再打开，验证数据保留。
3. 添加到主屏幕，联网打开一次后，断网关闭并重开，验证记录与统计可用。
4. 导出 JSON，在另一浏览器导入，核对比赛、标签、对手笔记；重复导入是替换，不产生重复。
5. 检查平板横竖屏、中文输入法、九宫格与弹窗滚动。
6. CSV 在表格软件打开，确认中文与备注正常。

私有托管首次登录需要网络，离线启动还受托管鉴权和设备浏览器影响，必须实机验收。清理网站数据会删除记录，请定期备份。当前不含 APK、双打、自动设备同步、逐板连续轨迹。
